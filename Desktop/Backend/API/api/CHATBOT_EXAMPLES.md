# 🧪 أمثلة على استخدام Chatbot

## أمثلة للاختبار

### 1. أسئلة بسيطة

```bash
# ما هو إجمالي مبلغ جميع طلبات الشراء؟
POST /chatbot
{
  "question": "ما هو إجمالي مبلغ جميع طلبات الشراء؟"
}
```

```bash
# كم عدد الفواتير المعلقة؟
POST /chatbot
{
  "question": "كم عدد الفواتير المعلقة؟"
}
```

### 2. أسئلة مع فلترة

```bash
# عرض جميع طلبات الشراء المعتمدة
POST /chatbot
{
  "question": "عرض جميع طلبات الشراء التي حالتها 'Approved'"
}
```

```bash
# عرض الفواتير الجاهزة للدفع
POST /chatbot
{
  "question": "عرض جميع الفواتير الجاهزة للدفع"
}
```

### 3. أسئلة إحصائية

```bash
# متوسط مبلغ الفواتير
POST /chatbot
{
  "question": "ما هو متوسط مبلغ جميع الفواتير؟"
}
```

```bash
# أعلى مبلغ في طلب شراء
POST /chatbot
{
  "question": "ما هو أعلى مبلغ في طلب شراء؟"
}
```

### 4. أسئلة بالإنجليزية

```bash
POST /chatbot
{
  "question": "What is the total amount of all purchase orders?"
}
```

```bash
POST /chatbot
{
  "question": "Show me all invoices with status 'Pending'"
}
```

### 5. أسئلة مع JOIN

```bash
# عرض طلبات الشراء مع الموردين
POST /chatbot
{
  "question": "عرض جميع طلبات الشراء مع أسماء الموردين"
}
```

## 📝 ملاحظات

- استخدم أسماء الجداول الصحيحة (lowercase)
- استخدم أسماء الحقول الصحيحة
- السؤال يمكن أن يكون بالعربية أو الإنجليزية
- النتائج محدودة بـ 10 صفوف في الإجابة
